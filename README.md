# Portfolio Website 

A high-fidelity clone of the [Jaxon Framer template](https://left-lifecycle-331001.framer.app/), built with **React Native for Web** using **Expo**.

This project demonstrates how to build modern, responsive, and visually stunning web applications using React Native primitives.

## 🚀 Features

-   **Exact Replica**: Pixel-perfect clone of the original design.
-   **Typography**: Integrated **Inter** font family for a premium look.
-   **Responsive Layout**: Optimized for web (desktop and mobile).
-   **Navigation**: Built with **Expo Router** for seamless page transitions.
-   **Interactive Components**:
    -   Custom Header with responsive navigation.
    -   Animated Hero section.
    -   Grid-based Services and Projects layouts.
    -   Reviews carousel style.
    -   Accordion FAQ section.
    -   Articles and Work Experience lists.

## 🛠️ Tech Stack

-   **Framework**: [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
-   **Web Support**: [React Native Web](https://necolas.github.io/react-native-web/)
-   **Routing**: [Expo Router](https://docs.expo.dev/router/introduction/)
-   **Fonts**: [@expo-google-fonts/inter](https://github.com/expo/google-fonts)
-   **Icons**: [Lucide React Native](https://lucide.dev/guide/packages/lucide-react-native)
-   **Animations**: [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/)

## 🏃‍♂️ Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/perkompus/react-portfolio.git
    cd react-portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the project**
    ```bash
    npx expo start --web
    ```
    This will launch the app in your default browser.

## 📁 Project Structure

-   `app/`: Expo Router pages and layout.
-   `components/`: Reusable UI components (Header, Hero, Services, etc.).
-   `constants/`: Global theme and color configuration.
-   `assets/`: Images and static resources.

## 🎨 Design System

The project uses a clean **Light Mode** aesthetic with high contrast:
-   **Background**: White (`#ffffff`)
-   **Text**: Black (`#000000`) & Dark Gray (`#666666`)
-   **Font**: Inter (Regular, Medium, SemiBold, Bold, Black)
